# APIs Collection

This repository contains multiple production-grade .NET APIs, each organized in its own subfolder under `APIs/` (e.g., `CRUD/`, `Reporting/`, `Analytics/`, etc.).

## Structure
- Each API has its own folder inside `APIs/` (e.g., `APIs/CRUD`)
- Each API folder contains its own `README.md` with specific setup, configuration, and usage instructions
- This main `README.md` provides an overview and guidance for working with all APIs in the repository

## Getting Started
1. Browse to the desired API folder under `APIs/` (e.g., `APIs/CRUD`)
2. Follow the instructions in that API's `README.md` for setup and usage

## Available APIs
- [CRUD API](CRUD/README.md): Finance Transaction CRUD API using ASP.NET Core, EF Core, and SQL Server
- (Add more APIs here as you create them)

## Adding a New API
1. Create a new folder under `APIs/` (e.g., `APIs/Reporting`)
2. Scaffold your .NET API project in that folder
3. Add a `README.md` in the new folder with details specific to that API
4. Update this main `README.md` to include your new API in the list above
